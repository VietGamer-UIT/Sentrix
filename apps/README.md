# Frontend & Dashboard Apps
**Người phụ trách:** Đoàn Hoàng Việt (Trưởng nhóm)

## Mục tiêu
- Xây dựng giao diện web-client cho khách hàng quét QR và ghi âm.
- Xây dựng Dashboard quản trị thời gian thực (Streamlit hoặc React).
- Quản lý chất lượng sản phẩm đầu ra và duyệt PR.

## Checklist ban đầu
- [ ] Khởi tạo dự án React/Next.js trong `web-client`.
- [ ] Khởi tạo dự án Streamlit/React trong `dashboard`.
- [ ] Cài đặt các thư viện UI cơ bản.
- [ ] Thiết lập kết nối cơ bản từ Frontend tới Firebase.
